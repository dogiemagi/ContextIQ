# Onboarding Guide

## Getting started

Create a workspace and pick a data region. Invite your teammates by email and assign each person a role. Then import your existing data and connect your first integration.

## Data import

You can import data from CSV files of up to 50 MB each. Larger datasets should use the bulk import API. Imports run asynchronously and you receive an email when they finish.

## Sandbox

Every workspace includes a free sandbox environment for testing integrations. Sandbox data is reset every 7 days.
